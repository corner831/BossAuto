BOSS直聘自动投递助手

登录 BOSS 直聘后，在职位搜索页打开本插件

⚠️ 请先在浏览器中打开 BOSS直聘职位搜索页 并登录，再点击"开始投递"。

以下三项会在任务开始时自动应用到 BOSS 搜索页的原生筛选器上（选"不限"则不调整）：

AI 智能匹配（大模型逐条打分）

下面这段「输出格式」是固定的、不可修改 —— 插件靠它解析分数： {"score":0-100,"reason":"...","risks":["..."]}

画像与 API Key 仅保存在本机浏览器存储中，只会发给上面这个接口地址。 每条职位产生一次请求，结果按岗位缓存，不会重复计费。

改了画像或阈值后，如果想重新评估"之前被 AI 拒掉"的岗位，需要先清空已处理记录 （否则同一岗位不会再看第二遍）。

新岗位刷新（翻完一轮后重新搜索）

建议保持较长的操作间隔，模拟真实手速，避免触发平台风控导致账号异常。 本插件不会读取或上传你的账号、Cookie 等任何信息，全部操作均在你本地浏览器内完成。
